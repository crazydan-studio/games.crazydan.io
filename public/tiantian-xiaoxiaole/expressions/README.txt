天天消消乐 · 表情包
====================

本压缩包由「天天消消乐」导出，包含：
  manifest.json —— 表情清单与元素槽位映射
  images/       —— 表情图片

线下部署方式：
  1. 解压本压缩包，把整个 expressions/ 文件夹上传到任意静态服务器，
     例如 Nginx / OSS / CDN / GitHub Pages，保证以下地址可访问：
     https://你的域名/expressions/manifest.json
  2. 打开游戏 → 表情管理 → 从服务器导入 → 填入上面的地址
  3. 其他设备即可加载同一套「天天」表情，秒变游戏元素。
